# SenMenuisier

Prototype visuel autonome de l’interface mobile SenMenuisier. Ouvrir `index.html` dans un navigateur ou servir le dossier avec `python3 -m http.server 8000`.

Le dépôt initial ne contenait pas d’application ou de logique métier. Les sélections de modèle, d’essence et de dimensions sont des interactions locales de démonstration, sans persistance ni calcul métier. Le statut, le score santé, l’estimation, la langue, la provenance et le passeport QR sont des éléments visuels à connecter aux services correspondants lorsqu’ils seront disponibles.
